# 월급수비대 PRD v1.0
작성: 2026-10-13 / 상태: 개발 착수용 명세

## 목표
귀여운 파스텔 도트 캐릭터와 RPG 미션으로 월별 지출, 저축, 대출 상환을 관리하는 **iPhone 홈 화면 설치형 PWA**. 사용자는 지출을 직접 기록한다. 금융기관 자동연동 또는 실제 송금 기능은 MVP에 없다.

## 화면 및 경험
- **홈 / 수비대 본부**: 급여주기(매월 25일~다음달 24일) 생활비 총예산·누적지출·남은돈, 카테고리 예산, 대출 보스 HP, 비상금, 큰지출 적립금, 오늘 미션, 기록 버튼. 지출을 아직 기록하지 않았을 때 가짜 지출/수치를 보여주지 말 것.
- **지출 기록**: 원화 금액, 날짜, 카테고리, 선택 메모/감정태그. 등록·수정·삭제, 중복 제출 방지. 월 예산과 최근 내역 즉시 갱신. 사용자 지출 인식은 카드 연동 없이 수동 입력을 기준으로 함.
- **대출 보스전**: 연 8% / 시작원금 500만 원 / 기존 월 납부 23만 원 / 월 추가 원금상환 목표 10만 원. '상환 기록'과 실제 은행 이체를 혼동하지 않도록 명시. 실제 납입액을 이자/원금으로 분리하여 원금 감소만 보스 HP에 반영. 상환방식·납부일은 확인되지 않았으므로 사용자 수정 및 표시; 시뮬레이션은 가정 명시. 다른 대출 월 20만 원은 금리·잔액 미확인으로 별도 기록.
- **저축 창고**: 비상금 현재 500만 원·우선목표 600만 원·월 적립 10만 원, 큰 지출 준비금 월 적립 10만 원(현재 잔액 미확인). 적립/인출/수동 잔액 조정 및 내역 관리.
- **미션/게임화**: 매달 월급 분배 확인, 매주 지출 결산, 추가 상환 확인, 비상금 적립. XP/배지/도트 애니메이션. 지나치게 죄책감 유발하는 문구 금지. 시각/소리 효과 토글.
- **통계·설정**: 카테고리별 소비, 급여 주기 비교, 월급일/예산/잔소리 강도/알림 시간/푸시 동의 설정, 데이터 내보내기·삭제.

변동 생활비: 식비 550,000원, 카페 120,000원, 데이트 250,000원, 쇼핑 150,000원, 러닝 120,000원, 기타 178,000원(총 1,368,000원). 예산 편집 가능.

## 실제 푸시 알림 (출시 필수)
- iOS 16.4+에서 Safari를 통한 **홈 화면 추가** 후 알림 동의. HTTPS, manifest, service worker 및 Web Push 구독 처리 필요.
- 서버가 발송해야 하는 정기 알림: 매달 25일 월급 분배(초기 제안 09:00 KST), 매주 일요일 주간 결산(20:00 KST), 월급 주기 종료일인 매달 24일 결산(20:00 KST).
- 조건부 알림: 같은 급여주기에서 지출이 변동 예산 80%(1,094,400원)에 **처음 도달**할 때 1회; 3일간 지출기록이 없을 때(사용자 설정 가능). 지출을 모두 수동 입력하므로 기록되지 않은 실제 소비는 알 수 없음.
- 푸시 구독 endpoint/키 안전보관, 인증 및 사용자 격리, VAPID 비밀키 서버에만 저장, 스케줄러 중복발송 방지, 실패 재시도, 구독해제, 권한거부 대응, 알림 딥링크, 알림 켜기/끄기, KST 및 DST 무관한 날짜 처리.
- 로컬 데이터만 있으면 서버에서 일정·미기록·80% 이벤트 확인이 어려우므로 필요한 최소 데이터 서버 동기화/인증 설계. 가능하면 민감한 거래 세부내용을 푸시 본문에 넣지 말 것.
- **실기기 테스트 전 푸시 완료라고 표기하지 말 것**. 실제 발송 가능 배포/백엔드 계정과 기기 알림 허용 필요.

## 기술 권장안
TypeScript + React/Next.js 모바일 PWA; manifest/service worker, 설치 가이드; 인증 가능한 DB(PostgreSQL 등)와 서버 API; Web Push 발송 라이브러리, 예약 작업. 금액 integer KRW. 정확한 금융 계산과 UTC 저장/KST 표시. 서버 측 데이터 접근 권한 검증, 환경변수 `.env.example`, 모의 데이터/실제 데이터 구분, 보안 및 데이터 백업/내보내기. 기기 오프라인 대응은 가능 범위에서 구현하고 동기화 충돌 정책 명시.

## 회계/데이터 규칙
월급 주기 기준 25일 00:00부터 다음달 24일 23:59:59 KST. 재정 배분, 소비, 계좌간 적립, 대출상환은 회계상 다른 종류로 분리해 이중계산 방지. 대출 원리금 상환 기록에는 원금/이자 별도 필드; 현재 잔액과 보스 HP는 실제 기록을 우선, 예상 결과는 가정 표시. 실계좌 연결 없음. 최초 잔액 모르는 큰지출 준비금은 `null`로 시작.

## 범위 제외
실제 송금, 증권 계좌 조회, 금융상품 추천, 카드/은행 자동 연동, 멀티유저 소셜 기능.
