Codex 실행 환경은 Cloudflare와 해당 공개 주소 요청을 HTTPS 프록시에서 `403 Forbidden`으로 차단합니다. 이는 앱 서버가 반환한 오류가 아닙니다. 공개 앱 검사 코드를 준비했으며, CI 결과와 사용자 실기기 관찰로 원격 검증을 이어갑니다. [무료 배포·복구 안내](cloudflare.md)를 참고하세요.

배포 보호 테스트 12개는 CI 대상 검증, 기존 키 보존, 기존 데이터 보호, 원래 DB와 ASSETS를 가진 빈 최초 설치의 복구, 비밀값 출력 방지와 임시 파일 삭제를 검사합니다. Cloudflare 예약 작업은 최대 50개의 D1 쿼리를 동적으로 관리하며, 최악의 예약·만료 기기 사례에서 47개 쿼리로 처리됩니다. 사용자 두 명씩 순환 점검하고, 오래된 DB 응답이 실제 재발송을 일으키지 않도록 선점 유효기간을 재확인합니다. 실제 무료 서버의 CPU 사용량은 원격 배포 후 측정해야 합니다.

**구현과 로컬 자동 검증은 완료했습니다. 공개 앱 화면과 iPhone 홈 화면 설치는 사용자 관찰로 확인했지만, 회원가입 성공과 실제 종료 상태의 푸시 수신은 미완료이며 출시 완료 조건은 아직 충족되지 않았습니다.** 사용자 브라우저의 Cloudflare 인증은 이 머신의 CLI 인증을 제공하지 않습니다. 서버의 발송 접수도 실제 기기 수신 증거가 아닙니다.

## 배포 후 남은 필수 검사

1. [Cloudflare 배포 문서](cloudflare.md)에 따라 GitHub 저장소를 연결하고 실제 HTTPS 주소와 무료 CPU 한도를 검증합니다. 일반 Node 서버는 [별도 배포 문서](deploy.md)를 따릅니다. VAPID와 암호화 키는 재시작 후 유지합니다.
2. iOS 16.4 이상 Safari에서 홈 화면에 추가하고 설치 앱에서 알림을 직접 허용합니다.
3. 앱을 종료·기기 잠금 후 다른 브라우저에서 같은 테스트 계정의 테스트 푸시를 요청합니다.
4. 실제 잠금화면 수신 시각, worker deliveryId, 알림 클릭의 딥링크 및 구독 해제 결과를 [실기기 기록표](iphone-test.md)에 기록합니다. 실제 예약 알림도 따로 확인합니다.

클라우드 재사용용 `install_script`, `start_skill`, Apple/Google/Mozilla/Windows 푸시 서비스 접속 허용 목록을 설정 초안에 저장했습니다. 초안 저장은 현재 네트워크 변경 적용이나 게시를 뜻하지 않습니다. 환경 설정에서 검토·저장 후 게시가 필요하며 새 작업 복원 검증은 아직 하지 않았습니다.

기기별 최신 스냅샷 방식의 오프라인 동기화는 서버 revision이 다르면 자동 병합하지 않습니다. 내보내기와 명시적 서버 다시 불러오기를 사용합니다. 로그아웃 전에 미동기화 기록을 내보내거나 확인 후 버릴 수 있습니다. SQLite 구성은 단일 영속 디스크를 공유하는 web/worker용이며 수평 확장·임시 serverless 저장에는 별도 DB 설계가 필요합니다. 푸시 원격 접수와 DB commit 사이의 프로세스 중단은 완전한 exactly-once를 보장하지 못하며 안정된 tag/Topic으로 중복 표시를 줄입니다.
